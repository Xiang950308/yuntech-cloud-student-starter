## 5. 用自己的話說

請求先檢查 Bearer 權杖，沒有身分回 401，角色不符合回 403。reporter 才能送事件，服務接著檢查 Content-Type、大小、欄位、ISO 8601 時區與欄位值，不合規則回 400。相同的 `event_id` 重送會回 409，合法事件才建立並加入 UTC 的 `received_at`。operator 才能查詢最新事件，顯示頁用 `textContent` 顯示查詢結果，避免事件文字被當成 HTML 執行。
